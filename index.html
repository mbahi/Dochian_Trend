Spike Analysis — Boom/Crash

Research tool, not a strategy: fetches real 1-minute history for each checked instrument, detects the large one-directional spikes Boom/Crash indices are built around (up-spikes on Boom, down-spikes on Crash), and reports the real gap and size statistics a Hunt-the-Spike or Fade-the-Grind strategy would need to be designed from actual data instead of a guess. Gap CV near 1 suggests the interval between spikes is memoryless (timing doesn't help); CV well below 1 suggests it's more clustered around the average (timing might help). "Grind" is the adverse move a position held from one spike to the next would have to survive, in the same ATR units as spike size. Mean spike ÷ mean grind is the number that actually determines long-run expectancy for a position held through every cycle; median spike ÷ P90 grind is a separate, more conservative read on how bad a typical bad cycle looks — neither is a real backtest.

Trend Following (Donchian) — fixed to H1/H4

H4 momentum filter + H1 Donchian(20) breakout entry  ·  SL: ATR(14)×2, trails at ATR(14)×3  ·  protective exit: Donchian(10) breach
0 = off (original pure-trailing behavior, letting winners run with no cap). Above 0: an H4-CLOSE-confirmed fixed R:R target. The moment price touches the target INTRABAR (even before H4 confirms), the stop tightens to breakeven immediately — so a reversal while waiting for confirmation costs nothing/little instead of giving the whole move back. The full-target exit only actually fires on the H4 candle that closes beyond it. Adverse checks (stop / Donchian(10) breach) are always evaluated before the target-touch check on the same bar, conservatively.

How this is computed

Multi-timeframe strip — 1m/5m/15m/1H streamed independently; each has its own structure. Swings — fractal highs/lows (2 bars either side). BOS — close breaks the last swing with the trend. CHoCH — breaks against it, flipping the bias.
Mean Reversion — BB(20,2σ) + RSI(2) extreme, both required, per Connors' short-term reversal research. An H4 regime filter blocks only counter-trend fades. TP1 targets the BB mid, TP2 stretches beyond it, SL is ATR(14)×1.5, with a 10-bar time-stop. Runs on whichever timeframe tab is selected.
Trend Following — H4 momentum sign must agree with an H1 Donchian(20) breakout. SL starts at ATR(14)×2, trails at ATR(14)×3, or exits on a Donchian(10) breach — whichever comes first. Fixed to H1/H4 regardless of the timeframe strip. Optional H4-confirmed R:R target, off by default (pure trailing).
